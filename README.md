Criação de um Dashboard para a atividade - projeto 3


Este dashboard foi desenvolvido utilizando Python, Dash, Pandas e Plotly Express, com o objetivo de realizar uma análise exploratória dos dados de um e-commerce. A aplicação apresenta diferentes visualizações gráficas que permitem compreender o comportamento dos produtos, seus preços, avaliações e distribuição por gênero, auxiliando na identificação de padrões e apoiando a tomada de decisões.
